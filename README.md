# FinSight AI

AI-powered investment research tools built during MBA at IE Business School.

## Tools
- **MF Selector** — Ranks Indian mutual funds using a weighted scoring model. Currently works for Index Funds, Large Cap, Mid Cap, and Small Cap. Multi Cap and ELSS are not yet supported.
- **Stock Portfolio Analyser** — Analyses your stock holdings and gives Buy/Hold/Trim/Exit recommendations. Works for NSE India and NYSE/NASDAQ USA.

## How to use
1. Download either JSX file
2. Open claude.ai
3. Upload the file and type: "render this artifact"
4. The tool runs instantly — AI analysis uses your own Claude credits

## Built with
Claude API · React · Live web search · Data from Tickertape, Rupeevest, AdvisorKhoj
